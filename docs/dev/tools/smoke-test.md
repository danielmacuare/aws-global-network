# Connectivity Smoke Test

`scripts/smoke_test.py` verifies inter-region network connectivity after a deployment by SSHing to each cell's bastion host and running `ping` to private hosts in every other region.

## Prerequisites

- `instances.json` generated by `deploy.py --json` (repo root by default)
- SSH private keys in `ssh-keys/` named `<region>-<env>.pem` (e.g. `ssh-keys/euw2-dev.pem`)
- SSH access to bastion hosts (security group allows your IP on port 22)

## Usage

```bash
# Run all cross-region tests (default paths)
python scripts/smoke_test.py

# Specify custom paths
python scripts/smoke_test.py --instances instances.json --key-dir ssh-keys/

# Filter to specific regions only
python scripts/smoke_test.py --regions euw2,use1

# Preview what would be tested without running SSH
python scripts/smoke_test.py --dry-run

# Increase timeout for slow links
python scripts/smoke_test.py --timeout 60
```

## Options

| Flag | Default | Description |
|------|---------|-------------|
| `--instances PATH` | `instances.json` in repo root | Path to the instances JSON file |
| `--key-dir DIR` | `ssh-keys/` in repo root | Directory containing SSH private key files |
| `--timeout SECONDS` | `30` | Per-test SSH/ping timeout |
| `--dry-run` | off | Print test plan without executing SSH commands |
| `--regions r1,r2,...` | all | Comma-separated region short-names to include (e.g. `euw2,use1`) |

## Output

The script prints a result table and summary for each cross-region pair:

```
Found 16 cell(s). Running 192 cross-region test(s).
  Testing euw2/cell1000 -> usw2/cell1000 ... PASS (12.345 ms)
  Testing euw2/cell1000 -> use1/cell1000 ... PASS (85.210 ms)
  ...

+-----------------------+-----------------------+--------+-----------+
| SRC (region/cell)     | DST (region/cell)     | STATUS | LATENCY   |
+-----------------------+-----------------------+--------+-----------+
| euw2/cell1000         | usw2/cell1000         | PASS   | 12.345 ms |
| euw2/cell1000         | use1/cell1000         | PASS   | 85.210 ms |
+-----------------------+-----------------------+--------+-----------+

Total: 192  Passed: 192  Failed: 0  Errors: 0
```

On failure, the SSH/ping output is printed inline for diagnosis.

## Exit codes

| Code | Meaning |
|------|---------|
| `0` | All tests passed (or `--dry-run`) |
| `1` | One or more tests failed |
| `2` | Configuration error (missing `instances.json`, no cells found, etc.) |

## instances.json schema

The file is generated automatically by `deploy.py --json`. It is a JSON object keyed by cell path:

```json
{
  "envs/dev/euw2/cell1000": {
    "bastions": {
      "bastion-euw2-dev-pub-0-cell1000": "35.178.244.94"
    },
    "private_hosts": {
      "private-euw2-dev-priv-0-cell1000": "10.1.0.148"
    }
  }
}
```

## Running as a post-deploy check

```bash
python scripts/deploy.py --json && python scripts/smoke_test.py
```

## Tests

```bash
uv run pytest scripts/tests/test_smoke_test.py -v
```
