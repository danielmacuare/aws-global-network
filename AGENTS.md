## Guidelines

- For any planning or implementation task use the docs at specs/
- specs/index.md serves as the summary of the project status
- Before implementing one of the features at specs/index.md do create a detailed plan specs/<feature-number>-<feature-name>-plan.md 
- Any design decision will be kept at specs/DESIGN.md
- Never hardcode secrets
- Never read secrets at *.env or env vars
